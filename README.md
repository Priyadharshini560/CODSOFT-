## Coffee Website ☕

A modern and responsive Coffee Shop Website built using HTML, CSS, and JavaScript.
This project showcases a stylish coffee shop landing page with sections like Home, About, Menu, Testimonials, Gallery, and Contact.
## Features
Responsive Navigation Bar
Attractive Hero Section
About Us Section
Coffee Menu Showcase
Customer Testimonials Slider (Swiper.js)
Image Gallery
Contact Form
Mobile Menu Toggle
Social Media Icons
Smooth and Modern UI
## Technologies Used
HTML5
CSS3
JavaScript
## Sections Included
🏠 Home

A welcoming hero section with a catchy headline and call-to-action buttons.

ℹ️ About

Brief introduction about the coffee shop and social media links.

☕ Menu

Displays different coffee and snack categories with images.

💬 Testimonials

Customer reviews displayed using a responsive Swiper slider.

🖼️ Gallery

Collection of coffee and refreshment images.

📞 Contact

Contact information and a simple contact form.
